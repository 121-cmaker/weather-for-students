# 유학생을 위한 간편 날씨 조회 서비스

## 1. 목적

한국에서 생활하거나 여행하는 유학생이 도시 이름을 입력해 현재 날씨와 오늘의 강수확률을 빠르게 확인할 수 있는 웹 MVP입니다. 복잡한 예보 화면 대신 출발 전 필요한 핵심 정보만 제공합니다.

## 2. 사용자

한국에서 생활하며 수업, 약속 또는 이동 전에 특정 도시의 날씨를 간단히 확인하려는 유학생입니다.

## 3. 문제와 범위

- 문제: 간단한 외출 판단에 필요한 날씨 정보를 빠르게 찾기 어렵습니다.
- 핵심 흐름: 도시 이름 입력 → 위치 검색 → 날씨 조회 → 결과 확인
- 포함: 도시 검색, 현재 기온·체감온도·풍속·오늘의 강수확률, 입력 검증, 로딩·정상·빈 결과·오류 상태
- 제외: 로그인, 즐겨찾기, 장기 예보, 알림, 개인화 추천

## 4. 공개 주소와 저장소

- 공개 주소: https://121-cmaker.github.io/weather-for-students/
- 저장소 주소: https://github.com/121-cmaker/weather-for-students

## 5. 사용 방법

1. 도시 이름에 한글 또는 영문 도시 이름을 입력합니다. 예: Seoul, Busan, 수원
2. **날씨 조회**를 누르거나 입력창에서 Enter를 누릅니다.
3. 결과 카드에서 현재 날씨, 기온, 체감온도, 강수확률, 풍속을 확인합니다.
4. 결과가 없거나 오류가 발생하면 화면의 안내에 따라 도시 이름을 수정하거나 **다시 시도**를 누릅니다.

## 6. 데이터 출처와 보안

- 데이터 출처: [Open-Meteo](https://open-meteo.com/)
- 사용 API: Geocoding API(도시를 좌표로 변환), Forecast API(현재 날씨와 오늘의 강수확률)
- 갱신 시점: 사용자가 조회를 요청한 시점에 API에서 데이터를 가져옵니다.
- 보안: API Key가 필요 없는 공개 API를 사용하며, 저장소에 비밀값을 포함하지 않습니다.

## 7. 사용성 및 접근성

- 입력창에 연결된 레이블을 제공합니다.
- 입력 오류는 aria-invalid와 안내 문구로 전달하고, 오류 시 입력창으로 초점을 이동합니다.
- 로딩 상태는 role=status, 요청 실패 상태는 role=alert로 알립니다.
- 키보드 Enter로 조회할 수 있으며, 작은 화면에서 버튼과 결과 카드가 한 열로 표시됩니다.

## 8. 검증 기록

세부 기록은 [verification/verification-record.md](verification/verification-record.md)를 참고하세요. 2026년 11월 16일 공개 URL에서 정상·빈 결과·입력 오류·긴 입력·Enter 키·375px 모바일 화면을 실제 확인했습니다. 입력 오류 뒤 이전 결과가 남던 문제를 수정했으며, 배포 후 같은 항목을 다시 확인합니다. 실제 오프라인 실패 재현은 아직 남아 있습니다.

## 9. 알려진 한계

- 외부 Open-Meteo 서비스와 네트워크 연결 상태에 따라 조회가 실패할 수 있습니다.
- 검색 결과의 첫 번째 위치를 사용하므로 같은 이름의 도시가 있을 때 사용자가 원하는 도시와 다를 수 있습니다.
- MVP 범위상 현재 날씨와 오늘의 강수확률만 제공합니다.
- 같은 이름의 도시가 검색되면 Open-Meteo의 첫 번째 결과가 표시될 수 있습니다. 예를 들어 수원의 결과는 사용자가 기대한 지역과 다를 수 있습니다.

## 10. 사용자 피드백과 반영

세 명의 실제 모바일 사용자 테스트를 기록했습니다. 참여자 1은 좁은 화면의 여백·카드가 다소 빽빽하고 미래 예보가 있으면 좋겠다고 말했습니다. 참여자 2는 도시 입력은 이해하기 쉽지만 온도 정보가 눈에 잘 띄지 않는다고 말했습니다. 참여자 3은 검색 뒤 화면이 간결하고 명확하다고 평가했으며 미래 며칠 예보를 요청했습니다. 현재 MVP의 기능·화면은 유지하고, 온도 정보 가독성 및 미래 예보는 후속 개선 후보로 기록했습니다. 세부 내용은 [사용자 테스트 기록표](verification/user-test-record.md)를 참고하세요.
