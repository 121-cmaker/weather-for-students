# 유학생을 위한 간편 날씨 조회 서비스

## 목적과 사용자
한국에서 생활하거나 여행하는 유학생이 도시 이름을 입력해 현재 날씨와 오늘의 강수확률을 빠르게 확인하는 웹 MVP입니다. 복잡한 예보 대신 외출 전에 필요한 핵심 정보만 제공합니다.

## 공개 주소와 저장소
- 공개 주소: https://121-cmaker.github.io/weather-for-students/
- 저장소 주소: https://github.com/121-cmaker/weather-for-students

## 사용 방법
1. 도시 이름에 한글 또는 영문 도시 이름을 입력합니다. 예: `Seoul`, `Busan`, `수원`.
2. **날씨 조회**를 누르거나 입력창에서 Enter를 누릅니다.
3. 현재 기온, 체감온도, 강수확률, 풍속을 확인합니다.

## 기능과 범위
- 포함: 도시 검색, 현재 날씨, 입력 검증, 로딩·정상·빈 결과·오류 상태
- 제외: 로그인, 즐겨찾기, 장기 예보, 알림, 개인화 추천

## 데이터 출처와 보안
- 데이터 출처: [Open-Meteo](https://open-meteo.com/) Geocoding API와 Forecast API
- 갱신 시점: 사용자가 조회할 때 API에서 데이터를 가져옵니다.
- 보안: API Key가 필요 없는 공개 API를 사용하며, 사용자 계정·위치·입력 기록을 저장하지 않습니다. 저장소에도 비밀값이 없습니다.

## 사용성 및 접근성
- 연결된 label, `aria-invalid`, 입력 오류 안내와 입력창 초점을 제공합니다.
- 로딩은 `role=status`, 요청 실패는 `role=alert`로 알립니다.
- Enter 키로 조회할 수 있고 작은 화면에서는 버튼과 결과 카드가 한 열로 표시됩니다.
