# 사용자 테스트 기록표

프로젝트 URL: https://121-cmaker.github.io/weather-for-students/

이 표에는 실제 사용자 3명의 관찰과 직접 말한 의견만 기록합니다. 이름, 연락처, 정확한 위치 등 불필요한 개인정보는 기록하지 않습니다.

## 공통 과제

1. Seoul 또는 알고 있는 도시를 입력해 현재 날씨를 확인한다.
2. 존재하지 않는 도시를 입력해 안내 문구를 확인한다.
3. 휴대폰 또는 좁은 화면에서 같은 작업을 시도한다.
